# Connect Claude Desktop to Arcade

In this guide, you’ll learn how to connect Claude Desktop to a local Arcade server.

---

## 1. Prerequisites

1. [Create an Arcade account](https://arcade.dev/signup)
2. [Get an Arcade API key](https://arcade.dev/api-keys)
3. **Install Python 3.10 or higher**  
   Verify your Python version by running:

   ```bash
   python --version
   # or
   python3 --version
   ```

---

## 2. Install Dependencies

Install the required Arcade packages:

```python
pip install arcade-ai
pip install arcade-google
```
